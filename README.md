# FinanEasy — Sistema de Controle Financeiro em Python

O **FinanEasy** é um projeto desenvolvido para o Hackathon Python do curso **Desenvolvedor Python – SENAI/DF**.  
Seu objetivo é criar um sistema funcional que permita ao usuário registrar receitas e despesas, calcular o saldo total e exibir um resumo financeiro, utilizando **Python e Programação Orientada a Objetos (POO)**.

---
